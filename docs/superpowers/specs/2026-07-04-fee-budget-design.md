# 费用板块设计文档

## 概述

在装修手记站点中新增「费用」一级板块，包含一张全屋预算汇总表，用于记录和跟踪各装修项目的费用明细与付款进度。

## 板块结构

```
mysite/content/docs/
├── fee/                    ← 新增
│   └── _index.md           ← 板块入口 + 预算汇总表
```

- `fee/_index.md`：同时充当板块首页和预算表格载体
- `weight: 2` → 排在「沟通」之前，位于侧边栏第二项
- LotusDocs 主题自动识别为侧边栏一级板块

## 页面内容

### 元信息

- **标题**：费用
- **描述**：装修全屋预算汇总与费用追踪

### 表格结构

| 列名 | 说明 |
|:---|:---|
| 项目 | 装修费用项目名称 |
| 总费用 | 该项目总预算金额 |
| 付费阶段 | 各付费节点描述 |
| 金额（分期） | 各阶段对应金额，用 `/` 分隔 |
| 已支出 | 已完工阶段金额累加 |

### 说明

- 表格行中的 TBD 表示该字段尚未确定，留待后续填写
